# 七猫小说

通过七猫官方接口提供小说分类、搜索、详情、完整目录和公开正文，签名与正文解码在本地完成。
不依赖个人中转服务；不包含账号登录或付费解锁。未知访问权限保持未知，接口明确声明免费时目录标为可读。

## 已知限制

- 当前宿主每章文本限制为 48 KiB，目录上限 5,000 章。超限时明确报错，不能截断伪造完整正文或目录。
  2026-11-06 抽测《剑来》目录有 1,279 章，但末章超出文本上限；这类超长章尚不支持。
- 仅小说；不包含七猫听书、短剧或漫剧。
- API 和网页运营稳定性不同，后续接口调整仍可能需要维护。

## 来源与验证

接口和请求结构参考公开 Legado 规则，迁移为 MgRead 原生公开 API 调用，没有运行旧规则执行器。
参考 [liufuyou/read 的 YCK 小说合集](https://github.com/liufuyou/read/blob/6d4eef3f3be97e0f582040033420c104949049ad/sources/yck-novel.json)
及 [七猫近期来源条目](https://www.yck2026.fun/yuedu/shuyuan/content/id/7895.html)。

构建与离线门禁：`npm run verify`；有界线上测试：`npm run test:live`。
Windows 必须使用仓库固定 Node/npm。打包输出 `artifacts/org.mgread.qimao-novel-1.0.0.mgplugin.js`。
