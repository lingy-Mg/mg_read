# zhi35 IPTV 增量规则

- 只消费 `zhi35/iptv` 的 `iptv.m3u`；其中已经包含 `live-china.m3u`，不重复合并，也不混入 FM 广播。
- 分类、显示名、台标来自当前播放列表。EPG 地址不等于可用回看，不生成节目、热门词或回看目录。
- 有 `tvg-id` 时以它建立频道身份，否则用去除临时授权参数的上游资源身份摘要；`tvg-name` 不保证唯一。
  同一频道的不同资源组成线路分组，IPv6 不转换为 IPv4，不移除真实播放 URL 的授权参数。
- 每次激活重新创建内存缓存；播放重新获取列表。只读列表与无扩展名地址的有界格式前缀，媒体主体由 Runtime 转发。
- `test:live` 覆盖全部分类和分页、按分类抽样封面与直播流，并写入忽略目录 `artifacts/`。
  网络失败保留报告，不静默过滤失效频道，不替换成其他站点。
