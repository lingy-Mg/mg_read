# zhi35 IPTV 增量规则

- 频道清单只消费 `zhi35/iptv` 的 `iptv.m3u`；其中已经包含 `live-china.m3u`，不重复合并，也不混入 FM 广播。
- 分类、显示名来自当前播放列表，台标保留其声明的原图身份。EPG 地址不等于可用回看，不生成节目、热门词或回看目录。
- 有 `tvg-id` 时以它建立频道身份，否则用去除临时授权参数的上游资源身份摘要；`tvg-name` 不保证唯一。
  同一频道的不同资源组成线路分组，IPv6 不转换为 IPv4，不移除真实播放 URL 的授权参数。
- 每次激活重新创建内存缓存；播放重新获取列表。HLS 播放前最多读取 8 KiB 清单元数据，检查 HTTP 状态和媒体/主清单标记；
  非 2xx、HTML、IPTV 总列表和连接失败通过公开来源错误上报，不把失效资源登记给播放器。FLV/MP4 不预读，媒体主体由 Runtime 转发。
- 401/403/451 使用 `source_access_blocked`；其他清单/连接失败使用 `source_media_resolution_failed`。
  消息保留频道名和 HTTP 状态，不包含地址、授权查询、headers 或响应主体，不自动更改代理路由。
- 台标策略集中在 `src/logos.mts`，发现/搜索/详情共用。连接失败的镜像转同一 GitHub 原图，`CTI3.pngg` 仅修正已核实的该处笔误。
  地方台正常原址保持；HEAD 确认缺失后，只按 `upload.112114.xyz/logo/` 目录精确同名回退，否则输出 null 并保留频道。
  不模糊猜测台标，不把传输失败判成缺失；HEAD 四路限流并缓存，目录最多 3 MiB、单飞缓存 24 小时，不读取图片主体。
- `test:live` 覆盖全部分类和分页、按分类抽样封面与直播流，并写入忽略目录 `artifacts/`。
  网络失败保留报告，不静默过滤失效频道，不替换成其他站点。
- `test:logos` 遍历全部频道及各表面，逐个验证所有已登记的唯一图片；缺图数和 `notRegistered` 表面单独保留。
