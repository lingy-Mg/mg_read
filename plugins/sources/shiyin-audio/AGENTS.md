# 十音·有声专辑增量规则

- 十音 `book_id` 与本地 `album_id` 是不同身份；只有精确回查 book_id 后才能读取本地音轨。
- `chapter:{book_id}:{chapter_id}` 与 `track:{book_id}:{track_id}` 明确提供方；后续播放不得因当前站内命中变化改走另一提供方。
- 十音检索合并相邻两页并保留 offset，不截断第一页剩余条目；不足或失败才使用听友检索。
- 保留完整标题及所有音轨；不用片花关键词或短时长推断删除章节。
- 封面仅取当前响应，不复制原规则离线封面表，不按同名作品猜封面。
- 本地映射/目录与听友目录共享最多 16 项、60 秒 JSON 内存快照；失败不缓存，刷新失效且并发单飞，播放地址每次重新获取。原提供方的分组加载不能因限流或映射变化自动切换提供方。
- 站内音轨用 HEAD 探测，不读取媒体主体。明确失败时，仅允许同一 book_id、完整标题相同且已知 track_no 与 index 一致的唯一备用章节；无法证明一致则报错，保持原 track ID 回传。
- `src/protocol.mts` 与 `src/discovery.mts` 由本来源独立拥有和打包；运行不加载其他来源。
