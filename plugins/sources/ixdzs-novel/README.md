# 爱下电子书

通过 `ixdzs8.com` 公开网页和目录接口提供网络小说推荐、搜索、详情、完整目录和公开正文。
作品使用官方书号；章节使用目录接口提供的 `ordernum`，不是客户端枚举位置。卷标题保留为章节元数据。

## 访问与边界

- 只访问规范站点和已核验的封面 CDN；没有个人中转或临时 PHP 接口。
- 旧规则中手工提取 token、拼接 challenge URL 的流程没有迁入。页面没有公开正文 section 时明确报访问受限。
- 上游 `None`、nopic 及不符合实际图片路径的地址不会登记为封面，不制造替代图片。
- 详情、目录和推荐快照均为进程内有界缓存。推荐快照最多五分钟；重启或过期后需要刷新。
- 保留宿主 5,000 章目录、48 KiB 单章上限，超限不截断。没有账号、下载 ZIP 或额外浏览器验证能力。
