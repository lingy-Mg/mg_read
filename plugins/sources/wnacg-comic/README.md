# 绅士漫画（下拉）

WNACG 独立图集来源，标记为成人来源。支持首页推荐及追加、搜索、详情和完整下拉页图。对应用户优先清单条目 7687，原规则更新于 2026-08-09；累计下载量仅作为热度参考。

一个站点图集对应一个章节，标题沿用图集原名。作品保留 aid；页图 ID 取真实路径摘要，不含临时签名或目录下标。每次 `getContent` 都重新获取详情和下拉页数据，使用站点新提供的图片签名；再次打开或刷新图集可更新时效地址。签名失效不是永久图片地址。

只解析公开图片 URL，不执行站点脚本。图集页数与唯一页图数必须一致，缺页或重复报错，不静默截断；最多处理 2,000 页。未知作者、语言、字数、更新时间为 null，页数独立展示。JPEG/WebP 由源站协商，页图不按文件扩展名伪造 MIME。

封面及图片由 Runtime 数据面获取；测试只探测有界图片前缀，不展示或持久化图像。固定仓库 Node/npm 下执行 `npm run verify`、`npm run test:live`。真实主程序、Android 和长期运行证据分别记录，不能以 Node 结果替代。
