# UAA 小说增量规则

- 只使用 www.uaa.com 公开 WebView 页面和同 Profile 搜索；不复制 Cookie、令牌或 UA，不使用失效旧 API intro/catalog。
- 书库为站点真实卡片的五分钟快照，追加必须沿用原快照；搜索页缓存保留页内余项，游标绑定查询。
- 19 位作品/章节 ID 保留字符串。完整目录验证连续编号和卷内声明总数，最多 5,000 章，不静默截断。
- 仅 `.ndc-acc` 为游客的章节允许请求；隐藏正文/会员预览明确失败，正文请求串行且至少间隔 3.5 秒。
- 离线 fixture 使用虚构内容；线上只记录数量、权限和资源前缀结果，不落地作品正文或图像。
- 固定 Node 执行 verify/test:live 和快速检查；Node 不执行 Cloudflare JS，其阻塞与真实 App CLI 单独报告。
