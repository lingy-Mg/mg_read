# UAA 小说

对应用户清单 7713 的小说类型；现有 UAA 音频、漫画、视频来源不覆盖小说。标记为成人来源。

通过公开 WebView 读取书库、详情和完整目录，通过同 Profile 请求公开搜索。推荐卡片保存五分钟快照，原样追加；搜索保留页内余项。不读取 Cookie、验证令牌或手写浏览器 UA，不连接失效旧版小说详情接口。

目录保留游客、会员及付费章节，只有游客章节请求正文。隐藏正文、受限预览和目录不完整都会失败；不以预览代替完整章节。正文串行并至少间隔 3.5 秒；目录最多 5,000 章，单章正文最多 48 KiB，超限明确报错，不截断。

固定仓库 Node/npm 运行 `npm run verify`、`npm run test:live`。Node 临时宿主不执行 Cloudflare JS，线上阻塞不能冒充通过；真实 Windows WebView 与 Android 必须分别记录。测试仅报告结构数量与资源前缀，不展示或持久化正文、图像。
