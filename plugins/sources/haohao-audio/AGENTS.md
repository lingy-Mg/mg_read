# 昊昊享听增量规则

- `src/protocol.mts` 是本来源私有协议与资源校验；不把 Context 或媒体字节复制到来源控制面。
- 首页使用已实测的 `rank` / `category`，详情使用 `album/{id}`；不恢复原 JSON 中用关键词拼出的推荐或最近更新。
- 章节 ID 使用真实 chapter ID，播放时查询当前目录的 `index`，禁止使用数组位置代替。
- 请求必须保留 Origin、Referer、时区与匿名会话头；封面不继承会话或 JSON 请求头。
- 专辑/目录 JSON 使用最多 16 项、60 秒的内存快照与并发单飞；`refresh` 绕过并使旧任务失去缓存归属。失败按 miss，不缓存媒体地址或字节。
- `test:live` 验证所有公开分类、追加、搜索身份、详情、完整目录及首中末音频与封面；不等于设备长时播放验收。
