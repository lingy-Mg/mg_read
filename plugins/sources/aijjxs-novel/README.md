# 久久小说网

独立 Node 小说来源：[久久小说网](https://www.aijjxs.com/)。支持首页推荐及追加、作品/作者搜索、详情、完整在线章节目录及公开正文。只接入在线阅读，不抓取整本下载包，封面经宿主资源代理加载。

综合调研条目 7778 在 2026-09-01 更新，调研显示累计下载 39,113；不是近三个月新增下载。此候选来自热度调研补充，不在原仓库 `aijjxs.com` 规则快照中；原审计中的 `9191net.com` 下载站分开识别。域名注册于 2022 年，仅作为入口年龄参考，不能保证长期运营。

作品及章节保留上游数字键，目录内“内容简介”按原名保留。搜索分页沿用公开结果编号，推荐追加使用五分钟有界快照。文件 KB 不转成字数，上传日期不伪装成出版日期。目录完整性指网站当前收录范围，不承诺与原著收录完全一致。

缺正文、占位、重复目录或未验证的目录分页明确失败。宿主限制为 5,000 章目录和单章 48 KiB UTF-8 正文，超限报错、不截断。只验证公开阅读，Android 和长期运行未验证。

使用仓库固定 Node/npm 执行 `npm run verify`、`npm run test:live`。快速与真实主程序检查证据保存在本次迁移的忽略目录。

2026-11-06 验证：10 项离线测试、确定性打包、线上测试及 Node 快速检查通过。样本目录 151 项，包含内容简介；简介/目录中项/末项文本为 472/3396/3216 字，另补测第一章小说正文 3207 字。推荐首页、追加列表、搜索、详情四个封面表面分别通过，两种月份封面路径均已覆盖。

真实 Windows 主程序 `0.14.8+497` 的发现、同书搜索、详情、151 项目录、三处文本及封面样本通过，退出码 0。该旧 EXE 未分别验证推荐追加及各封面表面，实际检查归一化为 **partial**。本机浏览器结构核验不替代 MgRead WebView 人工验收；Android 和长期运行未测试。
