# 久久小说网来源增量规则

- 页面只访问 `https://www.aijjxs.com`，封面仅登记 `image.jjjjxsw.com/UploadPic` 下 YYYY-MM 或 YYYYMM 两种已核验月份目录。
- 作品 ID 取详情数字编号，章节 ID 取在线目录中的真实数字键；目录里的简介仍保留原名。
- 搜索续页沿用站点公开结果编号与下一页，保留页内剩余项；不能重新搜索后把旧页码套到新结果编号。
- 文件大小不是字数，上传时间不是原著出版时间；未知元数据用 null。
- 仅接入公开在线阅读，不下载整本 TXT，不读 Cookie 或验证令牌；缺页、重复、占位及超限均失败。
- 变更执行 `verify`、`test:live`、单源快速检查；旧主程序聚合资源证据仍归一化为 partial。
