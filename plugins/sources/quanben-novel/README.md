# 全本小说网

独立 Node 小说来源：[全本小说网](https://www.quanben.io/)。支持首页推荐及追加、作品/作者搜索、详情、完整目录和公开正文，封面经宿主资源代理加载。来源是 `www.quanben.io`，与此前搜索空响应的 `qb5.io` 分开核验。

迁移参考为阅读规则站条目 7874，2026-09-27 更新，调研显示累计下载 38,244；不是近三个月新增下载。此条目来自综合热度调研，不在原仓库 888 条审计快照中。

作品保留上游 URL slug，章节保留数字键。目录由 HTML 首尾和公开 JSONP 中段组成，严格核对作品身份、唯一性和顺序；不把静态首尾当成完整目录。JSONP 只解析 JSON，不执行代码，不读取浏览器 Cookie 或验证令牌。未知字数、更新时间等返回 null。

“完整目录”指网站当前收录的完整目录；部分作品标题编号存在跳号，不能据此承诺与原著收录完全相同。正文占位、缺失中段、重复或宿主超限均明确失败。宿主限制为 5,000 章目录和单章 48 KiB UTF-8 正文，不截断。Android 和长期可用性未验证。

使用仓库固定 Node/npm 执行 `npm run verify`、`npm run test:live`，快速与真实主程序检查报告保存在本次迁移的忽略目录。

2026-11-06 验证：9 项离线测试、确定性打包、线上测试和 Node 快速检查通过。线上样本完整目录 3789 章，首/中/末正文 3281/2157/3451 字；推荐根页、推荐追加、搜索、详情四个封面表面分别通过。

真实 Windows 主程序 `0.14.8+497` 的发现、同书搜索、详情、3789 章目录、首中末正文及封面样本通过，退出码 0。该旧 EXE 只记录聚合封面，未独立记录推荐追加与各封面表面，实际检查归一化为 **partial**；Android、人工阅读和长期运行未验证。
