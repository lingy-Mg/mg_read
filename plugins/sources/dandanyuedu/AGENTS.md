# 蛋蛋阅读站点增量规则

- 搜索、详情、目录只调用公开 QQ 阅读 JSON API；分类发现只解析 `pin.qq.com/cate/{id}_{page}`。
- 搜索接口每次最多请求 30 条，并使用返回的 `nextstart` 作为游标；目录超过 5000 章或编码后
  2 MiB 时必须失败，不能截断伪装完整目录。
- 正文接口要求匿名 32 位 `Q-GUID`。每次激活用 `randomUUID()` 生成进程期值，不复用旧源固定值，
  不持久化、不记录，也不发送 Cookie、账号、签名或自定义 User-Agent。
- 搜索短 `bid` 按 QQ 规则加 `1100000000`；pin 分类页直接使用 `/detail/{bookId}` 的完整数字 ID。
- 正文只返回接口实际给出的字符串；无内容、错误或付费拒绝均抛错，不返回原始 JSON或伪造提示文字。
- Fixture 只保留虚构元数据和短正文，不保存线上响应、真实查询结果或正文。
