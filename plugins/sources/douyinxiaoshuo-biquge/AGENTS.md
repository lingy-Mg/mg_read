# 抖音小说-笔趣阁移动站增量规则

- 生产请求只使用公开 `ctx.http.fetch`；站点当前直接返回 UTF-8 HTML，不引入浏览器会话或验证绕过。
- 分类目录页为 `/fenlei/` 与 `/fenlei/{category}/{page}/`；详情目录通过 `/bqg/{book}_{page}/`
  分页，必须合并并去重后再返回完整目录。
- 搜索向 `/search/` 发送 UTF-8 表单正文；中文保持原始 UTF-8 字节，仅转义会破坏表单结构的分隔字符。
- 正文分页数来自标题中的 `(当前/总数)`，后续页为 `{chapter}_{page}.html`；不得把下一章误并入当前章。
- Fixture 只保留虚构标题、作者、路径和正文结构，禁止保存线上 HTML、正文或搜索结果。
