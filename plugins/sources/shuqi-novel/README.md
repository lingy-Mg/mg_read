# 书旗小说

从书旗官方网页读取首页推荐、搜索、作品详情与完整目录，从官方文本 CDN 读取目录明确标记为公开的章节。
VIP 章节保留在目录中并标记为锁定；本插件不包含账号登录或付费解锁。

首页推荐会轮换，一次浏览使用独立的有界推荐快照，追加页复用原快照。宣传标题会被作品正式名称替换，
搜索、目录与阅读始终使用官方作品 ID。请求使用真实的 `MgRead-Source/<版本> (<来源ID>)` 标识。

## 边界

- 公开正文只访问 `c1.shuqireader.com`、`c2.shuqireader.com`，JSONP 仅作为数据解析，不执行脚本。
- 读取前核对真实目录；VIP 章节不会向文本 CDN 发请求。
- 保留宿主 5,000 章目录、48 KiB 单章限制，超限不截断。未包含听书、短剧或书架同步。
- 推荐快照保存最多五分钟；进程重启或快照过期后需要刷新发现页。
