# 晋江文学城（公开阅读）

独立 Node 小说来源：[晋江文学城官方移动站](https://m.jjwxc.net/)。支持首页推荐及追加、作品搜索、桌面站详情和完整目录、移动站公开章节正文。VIP 与锁定项完整保留为不可读，不接入账户、登录、订阅或购买流程。

综合调研参考条目 1751（2026-11-05 更新）和 7838（2026-09-15 更新）。调研累计下载显示值分别为 2,487、37,973，不等于三个月新增下载。此来源只迁入官方公开阅读能力，旧规则中的账户、会员及付费功能不迁入。旧 App 搜索接口当前返回空结果，因此使用已验证的公开网页搜索。

作品与章节保留官方数字 ID，卷标题独立保留。搜索关键字按站点 GB18030 编码，使用精确固定的 `iconv-lite@0.7.3`；页面按响应 charset 解码。推荐追加使用五分钟有界快照。字数保留零值，未知元数据为 null。只有已核验官方 CDN 图片 URL 登记为封面。

搜索跳过官方目录没有任何章节记录的作品，避免同名未发表作品遮住已发表作品；其余结果保留站点顺序，当前页剩余项和真实下一页均保留。详情中的章节数取官方目录行数，零值按零保留。

正文仅提取公开阅读区，不混入作者备注和导航。缺少正文或访问受限时明确失败；目录超过 5,000 章或单章 UTF-8 正文超过 48 KiB 时报错，不截断。站点字体与版本可能改变，当前验证不能保证长期运行；Android 未测试。

使用仓库固定 Node/npm 执行 `npm run verify`、`npm run test:live`；快速与真实主程序检查报告保存在本次迁移的忽略目录。编码库 API 参考其[官方项目文档](https://github.com/pillarjs/iconv-lite)。

2026-11-06 验证：10 项离线测试、确定性打包、线上测试和 Node 快速检查通过。首页样本完整目录 41 章，18 章公开、23 章锁定；公开章节首/中/末文本为 5203/3810/3013 字。推荐首页、推荐追加、搜索、详情四个封面表面分别通过，锁定项请求按预期拒绝。

真实 Windows 主程序 `0.14.8+497` 的发现、搜索、详情、完整目录、公开正文与封面样本通过，退出码 0。首次检查曾选中同名无章节作品，报告已保留；搜索跳过无章节记录的作品后复核通过。旧 EXE 未独立验证推荐追加及各封面表面，实际检查归一化为 **partial**；Android、人工阅读和长期运行未测试。
