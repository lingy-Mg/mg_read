# 晋江官方公开阅读来源增量规则

- 页面只经公开 Context 请求 `m.jjwxc.net` 和 `www.jjwxc.net`；目录里的 `my.jjwxc.net` 仅解析章节身份，不请求。
- 搜索 kw 按 GB18030 编码，页面依据响应 charset 解码；`iconv-lite` 精确固定为 0.7.3 并随单 JS 内联。
- 阅读源搜索跳过官方目录无章节记录的作品；保留其余作品的站点顺序，分页偏移应用于筛选后的当前页。
- 完整目录保留卷标题、VIP 和锁定章节；优先使用官方 URL 中的 chapterid，缺少链接的锁定项保留站点章节列数字键。
- VIP、无公开链接或明确锁定的章节禁止正文请求；不迁入旧规则的登录、令牌、订阅、购买或账户操作。
- 封面限已核验官方 `i1-static` 至 `i9-static.jjwxc.net` 图片 URL，不伪造外站图片回退。
- 变更执行 `verify`、`test:live`、单源快速检查；旧主程序未分表面验收时仍记 partial。
