# 少年小说网来源增量规则

- 页面和封面仅访问 `https://www.snxsw.com`，图片限 `/img/<数字书号>.jpg|png|webp`。
- 目录以站点 select 公布的所有页为准，不能跟随超出页列表的假下一页；最新区不当成完整目录。
- `ycxsid` 列表的隐藏规则按原树同时解析，不能逐条删除再重新计算 nth-child。
- 正文只解码公开 Base64 段落，合并同章节 `_1.html` 等分段；不执行旧 JS，不读 Cookie、验证或会员令牌。
- ID 使用上游作品/章节数字键；缺页、缺段、重复、占位及宿主超限均失败，不返回部分内容。
- 执行 `verify`、`test:live` 和单源快速检查；当前旧主程序聚合资源证据需归一化为 partial。
