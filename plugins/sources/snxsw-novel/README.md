# 少年小说网

独立 Node 小说来源：[少年小说网](https://www.snxsw.com/)。支持首页推荐及追加、作品/作者搜索、详情、完整可见目录和公开正文。一个章节的全部网页分段合并后返回，封面经宿主资源代理加载。

迁移参考为阅读规则站条目 7751，2026-08-25 更新，调研显示累计下载 37,913；不是近三个月新增下载。该条目是综合调研的补充候选，不在 `liufuyou/read` 原 888 条规则快照内。域名有多年注册记录，但不能据此保证未来持续运营。

作品和章节保留上游数字 ID，未知字数等字段为 null。推荐追加使用五分钟有界快照，搜索按实际结果保留剩余项。目录遵循站点公布的页列表及 CSS 可见性；站点的标题编号可能有跳号，此插件保证返回网站当前完整可见目录，不承诺其收录与原著完全相同。

只解码公开 Base64 段落，不执行站点脚本、读取 Cookie 或迁入会员/验证流程。缺段、重复目录或“正在手打中”等占位文字明确失败。宿主限制为 5,000 章目录和单章 48 KiB UTF-8 正文，超限报错，不截断。Android 未验证。

使用仓库固定 Node/npm 执行 `npm run verify`、`npm run test:live`。快速与真实主程序检查报告保存在本次迁移的忽略目录。

2026-11-06 验证：9 项离线测试、确定性打包、线上测试及 Node 快速检查通过。线上样本完整目录 171 章，首/中/末正文 4119/3180/2946 字；推荐根页、推荐追加、搜索、详情四个封面表面分别通过。另一本作品预检为 8 页、454 个唯一目录项，正文包含 2–3 个分段。

真实 Windows 主程序 `0.14.8+497` 的发现、同书搜索、详情、171 章目录、三处正文和封面样本通过。该旧 EXE 只记录聚合封面，未独立记录推荐追加与各封面表面，实际检查仍归一化为 **partial**；Android、人工阅读和长期运行未验证。
