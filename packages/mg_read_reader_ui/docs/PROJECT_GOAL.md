# 项目目标

`novel_reader_ui` `0.4.0` 是供宿主 Flutter App 嵌入的文本小说与纵向漫画阅读器插件，
不是书城或内容平台。宿主负责内容、网络、鉴权、下载、持久缓存和用户状态；插件负责阅读
运行时、语义位置、内置 UI 与 Android/Windows 系统能力。

## 当前文本阅读目标

- 通过异步接口加载书籍信息、游标目录、稳定段落正文和全书索引定位。
- 提供横向分页、纵向滚动、章节衔接、书籍预览、目录、书签、进度与紧凑设置中心。
- 提供七套配色、六套原创背景，以及仿真、覆盖、平移、无动画四种横向翻页效果。
- 支持会话级三档自动阅读；运行状态和速度不跨会话持久化。
- 可选接入三级只读评论、宿主管理的远程章节状态和外部字体仓库。评论没有发布、回复、
  点赞、举报或许愿改编等写操作；插件不直接下载章节或字体。
- 阅读进度、设置和书签由宿主持久化；正文缓存和排版缓存保持有界，并以稳定语义锚点恢复。

## 当前漫画阅读目标

- 使用独立 `Comic*` 公共模型、数据源、状态存储、控制器、观察器和 `ComicReaderView`，不复用
  文本段落、字符偏移或分页模型。
- 只提供纵向渐进阅读；按稳定图片 ID 异步加载完整编码字节，维持已知比例占位，并让相邻章节
  连续衔接。
- 使用独立的图片内归一化进度、书签和展示设置，同时复用生命周期、常亮、失败归一化和请求
  世代等基础语义。
- 可选注入 `ReaderCommentFeed`，以 `ReaderCommentTarget.comicImage` 为稳定目标，在图片上叠放
  不改变图片占位的只读评论入口；未注入时完全隐藏。

## 平台与边界

- Android 为第一优先平台，Windows 为第二优先平台；Windows 构建和交互只能在 Windows 主机
  或对应 CI 验证。
- iOS、macOS、Linux 和 Web 不属于承诺支持范围。本轮 macOS 仅获授权用于 UI 人工验收。
- Android 和 Windows 原生层只承载常亮与沉浸等平台能力，不承载内容业务。
- 不在当前范围：书架、书城、推荐、搜索、账号、会员、付费、广告、DRM、文件解析、听书、
  划线笔记，以及任何评论写入或平台运营功能。

详细架构、公共 API、性能和验收契约以根目录 `AGENTS.md`、`docs/DEVELOPMENT.md` 与
`docs/UI_DESIGN.md` 为准。
