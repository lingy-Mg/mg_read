# Native Runtime implementation contract

Internal coordination document for the independently executable Rust backend. Root owns this contract and ABI.

- Build flag: `--dart-define=MGREAD_NATIVE_RUNTIME=true` selects native-only backend in the existing app.
- Rust host owns its loopback HTTP control and resource service. Flutter never runs a proxy/server.
- Windows executable at App sibling `native/mgread-native-host.exe`; start with `--root PATH --token TOKEN`, stdout first line JSON `{port,token,runtimeKind:"native-rust"}`. Keep parent-process ownership / kill on dispose.
- Android native variant Flutter MethodChannel `mgread/native_runtime`: `start` with `{token}` returns same ready map; `stop` stops the private worker Service. Service owns root `<filesDir>/mgread-native`, calls JNI `NativeRuntime.start(root,token)` returning ready JSON. JNI class full name `com.mgread.mgread_plugin_runtime.NativeRuntime`; library `mgread_native_runtime`. RPC is direct Rust HTTP; no large Binder results. Root Rust function `Java_com_mgread_mgread_1plugin_1runtime_NativeRuntime_start`.
- Internal HTTP: `POST /rpc`, `Authorization: Bearer TOKEN`, body `{id:string,method:string,params:object}`, response `{ok:true,result:any}` or `{ok:false,error:{code,message}}`. `POST /cancel` body `{id}` aborts host I/O and returns `{ok:true,settled:boolean}` after at most one second of waiting. Unsettled/failed cancellation ends the same worker generation. No automatic retry. Source public envelope matches existing typed invocation decoders.
- Import `plugins.native.import.v1` params `{path}`. Windows file selector path is direct; Android picker copies content URI into native private inbox and returns path. `plugins.native.importBytes.v1` params `{name,base64,expectedPluginId?,expectedVersion?}` for test/import streams, 64 MiB zip maximum (public Facade transfer retains its 32 MiB budget). Transfer identity is checked before installation. Public offer/list/plan methods use their existing `.offers.v1`, `.list.v2`, `.offers.plan.v1`, `.plan.v2` wire names.
- Proxy `runtime.native.proxy.v1` params `{url: string|null}`. Main invoke methods otherwise retain existing Dart invocation names and shapes. Unsupported capabilities report `unsupported`.
- Internal testing methods: `runtime.native.shutdown.v1` clean exit worker; `runtime.native.fault.v1` available only with explicit host test-mode, never ordinary production startup.
- ABI crate `abi/` is canonical. `mg_source_get_api_v1() -> *const SourceApi`. Source invoke input `{method:"discover"|"search"|"searchSuggestions"|"getDetail"|"getChapters"|"getContent",request:{...}}`. Plugin output `{ok:true,value:<source result>}` or `{ok:false,error:{code,message}}`.
- HostApi.call receives `{op:"http",url,headers?}` -> envelope value `{body,status,headers}`; all HTTP byte limits/cancel/timeouts belong to Rust host. `op:"storage.read"|"storage.write"|"storage.remove"` with `{area:"data"|"cache",path,value?}` where value is UTF-8 text, read absent returns null. `op:"cancelled"` returns bool. `op:"log"` accepts event text. `$resource` descriptor markers in plugin results resolved by Runtime before public output.
- Plugin manifest version 1 JSON: `{format:"mgread-native",engine:"native",abi:1,id,name,version,description,contentKinds:["novel"],capabilities:[...],targets:{"windows-x86_64":{path,sha256},"android-arm64-v8a":{path,sha256},"android-x86_64":{path,sha256}}}`. `.mgplugin` ZIP has manifest.json and those libraries. Rust installer owns integrity, target selection and atomic installation.
- Root owns `packages/mg_read_native_runtime/` except ABI consumption; agents must not edit this contract. Changes coordinate by message before implementation diverges.
