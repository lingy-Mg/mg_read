## 停止条件

- 找到所有者、公开边界和验证入口后立即停止读取。
- 只改一个文件时，以该文件头和测试为主，不为背景补读整个模块。
- 跨模块任务逐个边界加载；最多先增加一个相邻章节，禁止一次性展开整份核心规范。
- 旧原因只在冲突调查或迁移时从 Git 历史按文件名检索，不恢复活动文档树。
