# 发现页开发规范

## 分类导航栈

发现页的分类、榜单和分区跳转属于“发现页内部导航”，不是新的 GoRouter 顶层目的地。状态由
`DiscoveryPageController` 持有 `_stack`，每次打开分类压入一个不可变文档快照，返回时只移除
栈顶并恢复父级快照。

实现要求：

- `openCategory` 必须压入新层级；不能用替换当前文档的方式打开分类。
- `goBack` 必须只返回一层；栈少于两层时保持发现首页，不退出发现顶层页面。
- 分类请求加载中也必须保留 `canNavigateBack`，用户不能因为等待网络而失去返回入口。
- 分类请求尚未完成时返回必须立即恢复父级快照，并丢弃该请求的结果；不能要求请求先完成
  才允许返回。
- 返回时必须让当前请求失效；旧请求完成后不得把已返回的分类重新写回页面。
- 顶部返回按钮、`PopScope`、Esc、鼠标侧边返回键和系统返回必须调用同一个 `goBack` 语义。
- 全局返回先调用当前 root Navigator 的 `maybePop`，让发现页的 `PopScope` 先消费内部分类栈；只有
  当前页面没有可消费的返回动作时，才由路由历史离开发现页。
- 多级分类按“当前分类 → 父分类 → 发现首页”的顺序逐层返回，不能一次回到主导航。

## 页面状态与返回入口

发现内容的加载、空态和失败态不能删除当前层级的返回入口。加载态仍要显示发现顶部栏及返回
语义；失败或空态应保留父级快照，重试只刷新当前层级，不清空整个导航栈。

新增发现组件如果能打开新的页面或层级，必须同时提供：

1. 一个稳定的父级返回回调；
2. 一个 `PopScope` 或等价的系统返回接线；
3. Esc 和鼠标侧键与同一返回回调的自动化测试；
4. 多级嵌套至少覆盖两次打开、两次逐级返回以及加载中返回。

## 层级过渡与减动态

- 顶级、分类/榜单子页及详情页共用 `DiscoveryTopBar` 的安全区、40dp 高度、标题字阶、操作尺寸和左右边距。仅发现顶级显示数据源选择；后续层级仅显示同一栏中的返回、当前标题和必要操作，不能改用另一套二级页 chrome。
- 点击分类立即开始可中断的 shared-axis/推入式组合过渡。入场结束仍未取得数据时停在稳定 loading；数据提前到达可缩短入场，数据完成后以短过渡显示惰性列表。
- 层级切换使用稳定的页面存储 key，返回父级时恢复其已保留文档和滚动位置。加载中返回立即反向退出并使请求世代失效。
- `MediaQuery.disableAnimations` 为真时禁止大位移和缩放，层级瞬时切换；加载、失败、空态和逐级返回语义保持不变。
- 导航和文档加载共用 `discovery.navigation` owner span，只记录操作类型、请求世代、层级深度、计数和稳定错误码；不得记录 target、书名、书源显示名或其他内容标识。每次 span 只能以 success、error、cancelled、timeout 或 overloaded 之一结束。
- Android 发现子页使用 root Navigator 上的本地 `MaterialPageRoute`，不新增 GoRouter URL。controller 将不可变栈投影为只读父级快照链，系统可在 Predictive Back 手势开始时预览正确的直接父层；只有手势提交、route 真正 pop 后才调用 controller 的 `goBack`。取消手势不得改变快照栈、请求世代或诊断 span。

代码中涉及导航栈、请求世代或返回优先级的地方，应保留简短注释，说明为什么不能直接调用
`GoRouter.pop()`。

## 封面持久化（所有新增组件必遵守）

发现页所有来源封面，包括榜单、推荐、分类、轮播、列表、详情相关推荐以及未来新增组件，
必须遵守[全局封面持久化规范](cover-persistence.md)。内容网关只返回书籍主体和封面来源身份；
共享封面 Provider 在组件首次显示后先读取 `ContentLibrary.covers`，未命中才请求并写回。Widget
只能消费该 Provider 给出的 bytes、加载态或占位态，不得直接使用 `Image.network`、`NetworkImage`、
`HttpClient` 或 Persistence。

新增发现组件合入前必须逐项确认：

1. 来源内容经过 `SourceContentGateway` 返回封面来源身份，组件复用 `DiscoveryBookCover`；
2. 页面主体先显示，封面加载中显示明确加载态；本地命中不会重复请求，首次成功请求会写入全局缓存；
3. 缺图、坏图和网络失败只显示占位图，不阻断发现内容；
4. 测试覆盖命中、写入复用、加载态和失败占位；
5. 若组件增加新的内容投影或封面入口，同步更新全局规范和本清单。
