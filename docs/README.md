# MgRead 文档入口

根 `docs/` 只保留三个文件：

- [`core.md`](core.md)：唯一跨模块核心规范。按章节读取，禁止默认全文加载。
- [`development/README.md`](development/README.md)：把任务路径映射到一个核心章节。
- 本页：仅说明入口，不承载实现或历史。

开发时先读目标文件、最近的 `AGENTS.md` 和测试；只有出现跨文件边界才进入路由。单文件职责、
生命周期、IO 和状态所有权写在源码文件头，局部实现事实由代码与测试表达。过期方案、过程记录、
里程碑快照和重复说明不保留在活动文档中，必要时从 Git 历史检索。
